> **Using this template**
> 1. Click **Use this template** › **Create a new repository** (owner `AhmMZQ-m365`, public).
> 2. Clone it, then scaffold the solution at the root: `yo @microsoft/sharepoint` (keep the existing files).
> 3. Update the badges, the `node-version` in `.github/workflows/build.yml`, and this README.
> 4. Add the solution to the catalog in [AhmMZQ-m365/.github](https://github.com/AhmMZQ-m365/.github/blob/main/profile/README.md).
> 5. Publish a release (`v1.0.0`) with the `.sppkg` attached, then delete this box.
